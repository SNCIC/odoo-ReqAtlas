## 2. 上下文（Context）

Agent 需提供四类受控能力（追问、建模草案、完整性检查、通俗解释），且**绝不能**把
推测当作事实写入库（P3、P4）。核心风险是模型输出不稳定、供应商可替换、链路必须可审计。
需要一套确定的编排、可替换的模型接入与可验证的输出结构。

上游 §2.2 裁定"Agent 只产出 ChangeDraft，应用时服务端二次校验"。需要据此定义编排边界与
数据权限边界。

## 3. 决策（Decision）

1. **自研编排**：组件链为 Context Builder → Retriever → Prompt Registry →
   Provider Adapter → Schema Guard → Domain Guard → Draft Store → Run Audit。
2. **Provider Adapter**：统一接口，默认 OpenAI 兼容实现，供应商可配置、可完全禁用外发。
3. **JSON Schema 约束输出**：四类任务（追问 / 建模 / 检查 / 解释）各有带版本的 Schema，
   `prompt_version` / `schema_version` / `provider` / `model` 写入 `agent_run`。
4. **Agent 无数据库写权限**：只产出 `change_draft`（含 `operations`、`assumptions`、
   `findings`、`based_on_revision`），绝不直接写 `model_object` / `model_relation`。
5. 应用草案时服务端**二次校验**：当前 revision、权限、来源、Domain Guard 全部通过后，
   才转为 ChangeSet 应用；`assumptions` 永远不能进入基线。
6. 安全门禁：最小上下文（按任务只传必要片段并做权限过滤）、Schema 先行、
   来源必填、预算与超时、格式失败最多自动修复一次后转人工。

## 4. 理由（Rationale）

- 自研编排链路显式、可调试、可审计，避免隐式框架行为（§2.3 否决 LangChain 类框架做核心）。
- Provider Adapter 使供应商可替换、数据可不出境（可完全禁用外部模型）。
- Schema 约束 + 两次校验把"模型幻觉"挡在事实源之外（P3 + P4）。
- Agent 无写权限从架构上保证"AI 修改先以差异草案呈现"。

## 5. 后果（Consequences）

### 正面

- 输出结构化、可校验、可回归；金样例集可稳定评估质量。
- 数据外发策略可按项目级别控制与关闭。
- 失败可降级：Agent 不可用时手工建模、校验、评审、文档仍可用（§7.5）。

### 负面

- 自研编排需要维护 Prompt Registry、上下文构造与错误分类，工作量大。
- 严格 Schema 可能降低模型表达自由度，需反复调优 Prompt。
- 无统一 Agent 框架的现成可观测与工具生态，需自建。

### 风险

- 提示注入、悬空引用、未知枚举、无来源事实等攻击面（M5-09）。对策：Schema Guard +
  Domain Guard + `untrusted_content` 标记 + 服务器固定工具权限。
- 无限重试或超预算。对策：格式失败最多自动修复一次，项目级预算与停止开关。

## 6. 被否决的替代方案

| 方案 | 否决原因 |
| --- | --- |
| LangChain 类框架做核心编排 | 隐式链路、升级与调试成本高（§2.3） |
| 让 Agent 直接写数据库 | 违反 P3，推测可能进入事实源 |
| 无 Schema 的自由文本输出 | 不可校验、不可回归、无法逐项审阅 |
| 多 Agent 自治 / 全自动方案生成 | 首版明确不做（§1.2） |
| 单一硬编码供应商 SDK | 不可替换、数据策略无法按项目关闭 |

## 7. 验证方式

1. 能力禁用测试：关闭外部模型后系统仍可完成手工建模与文档（M5-01）。
2. 校验链测试（M5-09）：跨项目提示注入、超预算、悬空引用、未知枚举、无来源事实
   必须全部失败。
3. 应用测试（M5-07）：基于过期 revision 的草案被拒绝；`assumption` 无法进入基线。
4. 状态机测试（M5-05）：AgentRun 状态流转与错误分类正确，格式失败最多修复一次。
5. 金样例回归（M5-08）：折扣审批、信用异常、采购质检、职责冲突四组中文样例通过。

## 8. 重新评估触发条件

- 某通用 Agent 组件经 P0 证明显著节省工作（§2.3 的重新评估触发）。
- 数据政策要求模型完全本地化，现有 Adapter 无法满足。
- JSON Schema 约束在真实任务中持续阻碍有效输出，需引入更灵活的结构约束。
- 检索质量或召回不足影响 Agent 结论可靠性（联动 ADR-009）。
