### 8.1 冻结基线锚点（M0 一次性，非永久常量）

> 本块登记 M0 复核所用**唯一输入**的哈希。它是 **M0 阶段的一次性锚点**——M0 关闭后，
> 该哈希随 bundle 演进作废，必须在下一里程碑**重新登记**。**不得**把它当作永久硬编码
> 常量固化进任何代码或断言（与复核清单"禁止魔数断言"一致）。

| 项 | 值 |
| --- | --- |
| path | `packages/testkit/fixtures/demo-trade/model-bundle.json` |
| sha256 | `1a54c6e3158fb2d7a079fad244e30fd774c6b453e06d3859785978a184e03c62` |
| bytes | `27549` |
| counts | `modelObject 33 / modelRelation 54 / evidence 3 / evidenceLink 17 / viewLayout 15` |
| 权威声明方 | `<>`（如总指挥 / `sample`） |
| 适用里程碑 | `M0`（关闭后作废，需重新登记） |

**复核要求**：权威声明方给出的哈希**可核对一次即可**，但复核人仍须**自行重算**，
不得把哈希当作"信任即可"的值。重算命令（Windows PowerShell）：

```powershell
(Get-FileHash -Algorithm SHA256 -Path packages/testkit/fixtures/demo-trade/model-bundle.json).Hash.ToLower()
```

重算值须与上表 `sha256` 逐字符相等；不等则视为基线不一致，阻断复核。
