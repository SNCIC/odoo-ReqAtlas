# 典型痛点：离散制造

> **版本**：v0.1　**发布日期**：2026-10-04　**状态**：`draft`
> **评审**：需实施专家评审
> **内容定位**：模板候选，需客户核实。行业知识包提供调研参照，**不是客户事实**。
> `package_id = mfg.generic`　`package_version = 0.1.0`
>
> 用途：知道制造现场哪里值得深挖。每条痛点给出「征兆」（访谈中如何察觉）与「追问方向」。
> 「编号」列即 `item_key`，与 `package_id` 组合构成该条目的 `template_origin`。

## 使用说明

- 「征兆」是**待验证的线索**，不是客户结论；发现征兆不等于痛点成立。
- 「可能的现状原因」为经验假设，须经客户核实，不得直接写入事实。
- 「关联对象类型」取值：人物、组织、事项、决策、异常、系统、数据对象。
