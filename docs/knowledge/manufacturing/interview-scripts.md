# 岗位访谈话术库：离散制造

> **版本**：v0.1　**发布日期**：2026-10-04　**状态**：`draft`
> **评审**：需实施专家评审
> **内容定位**：模板候选，需客户核实。行业知识包提供调研参照，**不是客户事实**。
> `package_id = mfg.generic`　`package_version = 0.1.0`
>
> 用途：面向「照着念也能问下去」的新手场景。问题用**业务语言**，不要求新员工理解技术术语。
> 每张问题卡的结构：主问题由 `#### Qn` 标题承载；下表 5 行为问题卡字段；卡下列出 `item_key`。

## 通用使用规则

1. **先要例子，再要规则**。先请客户讲一个最近发生的真实例子，再问「一般情况」。
2. **不要暗示答案**。把「你们是不是按 BOM 领料？」改为「领料的时候，怎么知道该领多少？」
3. **听异常比听正常重要**。缺料、返工、报废、急单里藏着真正的流程。
4. **每题都有停止条件**，达到即停，避免无限追问。
5. **记录用客户原话**；结论标注来源。所有从本库得到的内容一律标为「模板候选」，须客户核实。
6. 遇到客户黑话，回到 `terminology.md` 核对，并当场确认定义。

## 危险信号

- 计划只靠少数人脑子里的经验，无书面依据。
- 同一批活有多份计划表，且说不清以哪份为准。
- 「缺料了才知道」，无齐套校验。
- 插单无审批、无通知，下游靠打听。
- 交期承诺不看产能与料况，只凭感觉答应。
