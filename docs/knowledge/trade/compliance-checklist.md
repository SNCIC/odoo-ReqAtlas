# 合规要点：通用贸易

> **版本**：v0.1　**发布日期**：2026-10-04　**状态**：`draft`
> **评审**：需实施专家评审
> **内容定位**：模板候选，需客户核实。行业知识包提供调研参照，**不是客户事实**。
> `package_id = trade.generic`　`package_version = 0.1.0`
>
> **总声明：以下所有条目均为「提醒核实，不替代法律意见」。** 合规结论必须由客户的税务、法务、审计或相应专业人员确认，本清单只用于**在访谈中提出该问的问题**，不构成任何合规判断或承诺。

## 使用说明

- 每个条目给出「需关注的记录与控制点」与「需要向客户确认的问题」。
- 「提醒核实，不替代法律意见」逐条标注，避免被误用为合规依据。
- 发现客户做法与通用要求不同时，**记录现状即可**，不在访谈中下结论。
- 涉及具体金额、税号、身份证号等敏感信息时，记录中应脱敏。
