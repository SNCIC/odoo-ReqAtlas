## 0. 适用范围

| 维度 | 说明 |
| --- | --- |
| 行业 | 通用贸易（以商品买进卖出为主，自有制造环节较少或较浅） |
| 细分场景 | 内贸批发/分销为主，含少量进出口 |
| 企业规模 | 中小企业（多部门协同，尚未完全信息化） |

预置重点：**报价到回款**、**采购到付款**——最通用的跨部门闭环（产品设计文档 §9.3）。

## 1. 角色流程骨架

> 组成一。预置为可修改底稿；实例化后每条对象均为「模板候选」。

### 1.1 组织与岗位

| 岗位 | `template_origin` | 主要职责（模板候选） |
| --- | --- | --- |
| 销售 | `trade.generic#role.sales` | 获客、报价、合同/订单、跟单、回款跟进 |
| 采购 | `trade.generic#role.purchase` | 请购、询比价、下单、跟交期、供应商管理 |
| 仓库 | `trade.generic#role.warehouse` | 收货、上架、拣货、发货、调拨、盘点 |
| 财务 | `trade.generic#role.finance` | 开票、收付款、核销、费用、结账、对账 |
| 人事 | `trade.generic#role.hr` | 入转调离、考勤、薪酬、权限开通回收、档案 |
| 生产（可选） | `trade.generic#role.production` | 排产、领料、报工、质检、委外（有制造环节时启用） |
| 管理层/审批人 | `trade.generic#role.approver` | 折扣、超信用、超采、付款、费用等例外审批 |

> 提示：小型企业常一人多岗（如销售兼跟单、财务兼人事）。访谈时须确认**实际承担者**，不能按岗位表假设。

### 1.2 主流程（两条端到端闭环）

**闭环 A：报价到回款（Quote-to-Cash）**

| 步骤 | 触发 | 责任岗位 | `template_origin` |
| --- | --- | --- | --- |
| A1 商机/需求确认 | 客户询价 | 销售 | `trade.generic#flow.q2c.01` |
| A2 报价单 | 需求明确 | 销售（折扣超权限转审批） | `trade.generic#flow.q2c.02` |
| A3 销售订单 | 客户确认/签约 | 销售 | `trade.generic#flow.q2c.03` |
| A4 信用与库存校验 | 订单确认前 | 销售/财务 | `trade.generic#flow.q2c.04` |
| A5 出库/发货 | 订单确认 | 仓库（缺货转采购/生产） | `trade.generic#flow.q2c.05` |
| A6 开票 | 发货（或约定节点） | 财务 | `trade.generic#flow.q2c.06` |
| A7 收款与核销 | 客户到账 | 财务 | `trade.generic#flow.q2c.07` |
| A8 账龄跟进/催收 | 逾期 | 财务/销售 | `trade.generic#flow.q2c.08` |

**闭环 B：采购到付款（Procure-to-Pay）**

| 步骤 | 触发 | 责任岗位 | `template_origin` |
| --- | --- | --- | --- |
| B1 请购 | 低库存/销售需求/人工 | 仓库/计划/需求部门 | `trade.generic#flow.p2p.01` |
| B2 询价/比价 | 请购批准 | 采购 | `trade.generic#flow.p2p.02` |
| B3 采购订单 | 选定供应商 | 采购（超权限转审批） | `trade.generic#flow.p2p.03` |
| B4 收货/送检 | 供应商到货 | 仓库/质检 | `trade.generic#flow.p2p.04` |
| B5 入库/上架 | 验收合格 | 仓库 | `trade.generic#flow.p2p.05` |
| B6 供应商发票登记 | 收到发票 | 财务 | `trade.generic#flow.p2p.06` |
| B7 三单匹配 | 发票登记后 | 财务 | `trade.generic#flow.p2p.07` |
| B8 付款与核销 | 匹配通过/到期 | 财务（超权限转审批） | `trade.generic#flow.p2p.08` |

> 交叉点：A4 信用校验依赖财务；A5 缺货触发 B1；B2 比价依赖历史采购价与供应商记录；A7/B8 在财务汇合。

## 6. 参考样例说明

> 组成六。通用演示数据，仅用于预习与产品演示。

- 参考样例为**中性化、虚构的示意数据**（如「某分销企业」），**不得**使用真实企业名、人名、真实金额或真实单据号。
- 用途：
  1. 顾问预习：在进现场前走一遍代表性场景，熟悉术语与流程节点。
  2. 产品演示：展示「模板 → 访谈 → 建模」链路时使用，不承诺任何客户事实。
- 样例中所有对象同样标注 `template_origin` 与「模板候选」，演示中产生的对象不得直接进入客户基线。
- 样例与真实项目的边界：样例可被客户**参照修改**，但客户确认后的结果只属于该项目，不回流本包。
