# 目标设备与浏览器清单（建议值）

> 对应实施方案 §6.1（M0-01）产出物之一。
>
> **状态：待产品负责人确认。** 下表为工程侧基于「企业桌面现代浏览器 + 普通办公机」的**建议值**，
> 用于 M0 性能阈值冻结（§8.3）的目标口径；未经产品负责人确认前不得作为验收硬阈值。

## 1. 目标设备档位

| 档位           | 定位                    | 建议最低配置                              | 说明                  |
| -------------- | ----------------------- | ----------------------------------------- | --------------------- |
| A · 主力机型   | 企业标准办公台式/笔记本 | 4 核 CPU / 16 GB RAM / SSD / 1920×1080    | 2D/3D 目标体验基线    |
| B · 普通办公机 | 存量普通办公机          | 4 核 CPU / 8 GB RAM / 集成显卡 / 1366×768 | 必须可用，3D 允许降级 |

## 2. 浏览器与操作系统

| 组件          | 建议支持范围                     | 备注                 |
| ------------- | -------------------------------- | -------------------- |
| Chrome / Edge | 最近 2 个大版本（Chromium 内核） | **首要支持目标**     |
| Firefox ESR   | 当前 ESR                         | 兼容性验证，非首要   |
| Safari        | macOS 最近 2 个大版本            | 有条件支持           |
| 操作系统      | Windows 10/11；macOS 13+         | 桌面优先             |
| 移动端        | 仅只读查看（可选）               | MVP 不承诺移动端编辑 |

## 3. 分辨率与输入

| 项             | 建议值                                  |
| -------------- | --------------------------------------- |
| 最小可用分辨率 | 1366×768（B 档）                        |
| 推荐分辨率     | 1920×1080（A 档）                       |
| 输入方式       | 鼠标 + 键盘（画布编辑必需）；触摸板可用 |

## 4. 网络与部署前提

| 项       | 建议值                                   |
| -------- | ---------------------------------------- |
| 部署形态 | 私有化部署，局域网/企业内网访问          |
| 网络     | 稳定内网；3D/文档等重资源允许懒加载      |
| 图形能力 | 需 WebGL 能力检测；不支持时自动降级为 2D |

## 5. 待确认问题（产品负责人）

1. A/B 两档机型的最低配置是否与客户现有办公机一致？
2. 是否需要正式支持 Firefox / Safari，还是仅 Chromium 系？
3. 移动端是否只读即可，或需要完整编辑？
4. 设备清单是否需要纳入具体客户环境实测样本？

> 确认后，本文件与 `performance-baseline.json`（§8.3）一并作为 M0 验收口径。
